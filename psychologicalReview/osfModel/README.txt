This folder contains the scripts needed to run the simulations reported
in

  ANONYMOUS (under review).  An associative-learning account of infants’ looking in action-efficiency paradigms understanding

The simulations are run using a modified version of the Lens neural network
simulator (http://tedlab.mit.edu/~dr/Lens/).  Binary executables for Windows,
OSX, and Linux are provided at

   http://www.cnbc.cmu.edu/~plaut/Lens

To install, uncompress the appropriate file and follow the directions in the
README file.




To run the simulations reported in the main paper, go here:

project/
└── Main Simulations/
    ├── sims.in



To run the simulations reported in the supplementary materials, go here:

project/
└── Supplementary Simulations/
    ├── supSims.in
